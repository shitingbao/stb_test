```
### TC-028: ✅ 通过
```
依据: 后端 Info 方法中：
```go
sumPending, err := dao.WalletBill.Ctx(ctx).
  Where(colBill.WalletId, wallet.Id).
  WhereNotIn(colBill.Status, []int{Paid, NoPay}).
  Sum(colBill.PendingAmount)
```
- 待还款总金额 = NOT IN(已还清, 无需付款) 的 PendingAmount 之和
- **注意**: 待还款总金额 ≠ Σ(待还款) - 审核中
- 后端返回 pendingRepayTotal = ΣPendingAmount（全部未还）
- 前端单独拿到 underReviewTotal
- 前端显示的待还款总金额和审核中金额是独立的两个值
- **用例中描述的公式"Σ待还款金额-审核中金额"与后端实现不一致**
- ⚠️ 后端实现是待还款总金额 = 全部未还账单的PendingAmount之和
